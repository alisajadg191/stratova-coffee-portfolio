# Stratova Coffee brand alignment

This version was requested to promote Stratova’s own identity. The earlier Little Ritual concept is preserved separately.

Measured directly from the rendered Stratova homepage on 31 October 2026:

| Role | Site token | Value |
|---|---|---|
| Primary wine | --wine | #521D2C |
| Paper / ivory | --paper | #F7F4EE |
| Ink | --ink | #292524 |
| Dividers / taupe | --line | #D8CDC8 |
| Muted copy | --muted | #6B615E |
| Heading | --heading | Syne |
| Body | --body | Hanken Grotesk |

Source: https://stratova.co.uk/

The STRATOVA wordmark on that site is typeset in Syne, weight 800, letter spacing -1px. This concept uses that same typeface and weight, with COFFEE as the descriptor. SVG cup and bag wordmarks are converted to vector outlines for reliable rendering in images. Package colour variations remain within wine, muted wine and charcoal.

Self-hosted font files were copied from the existing public brand assets:
- https://stratova.co.uk/assets/fonts/syne-latin.woff2
- https://stratova.co.uk/assets/fonts/hanken-grotesk-latin.woff2

Both use the SIL Open Font License. Their full licence notices are bundled beside the web and offline fonts. The offline renderer uses static font instances converted from those same files. No font-service request is needed by the finished website.

Licence sources:

The website remains labelled as a fictional coffee concept rather than an operating coffee shop. No payment functionality or production deployment has been added.
